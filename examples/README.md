# Examples

Start with [a single element](element/README.md) before building a [DCB](dcb/README.md) or [MMB](mmb/README.md) model. Commands in each guide are run from the repository root.

Each specimen example keeps generator scripts and JSON configuration at its top level. `inputs/` contains supplied decks; `data/`, `figures/`, and `plots/` separate historical comparisons from their plotting code. New models, solver output, and regenerated plots belong under ignored `runs/` folders.

Historical input names and CSV labels can differ from their actual parameters. Read each example guide and the [validation notes](../docs/validation.md) before using a curve as a reference.
